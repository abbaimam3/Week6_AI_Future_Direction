# Week 6 Assignment: AI Future Directions

This directory contains the submission for the "AI Future Directions" assignment.

## Directory Structure

*   **Part 1: Theoretical Analysis**
    *   `Part1_Theoretical_Analysis.md`: Answers to Q1 (Edge AI) and Q2 (Quantum AI).
*   **Part 2: Practical Implementation**
    *   `Part2_Task1_EdgeAI.ipynb`: Jupyter Notebook for training a lightweight CNN and converting it to TensorFlow Lite.
    *   `Part2_Task2_IoT_Concept.md`: Design document for a Smart Agriculture IoT system.

## Setup & Installation

1.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## How to Run

### Task 1: Edge AI Prototype
Open the Jupyter Notebook:
```bash
jupyter notebook Part2_Task1_EdgeAI.ipynb
```
Run all cells to train the model and generate the `.tflite` file.
